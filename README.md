# 银龄康护 · 30天具身智能全课程学习平台

可部署到GitHub Pages的纯静态中文学习网站。无后端、无构建步骤、无第三方前端依赖，字体与页面插图不依赖外部下载。

## 打开网站

解压后双击 `index.html` 即可阅读与使用。推荐部署到Pages或通过本地HTTP服务使用，以获得稳定的浏览器存储行为。文件必须放在一起，保持相对路径不变。

若已安装Python，可在此文件夹打开终端运行 `python -m http.server 8000`，访问 `http://localhost:8000/`。这只是可选预览方式，部署时不需要Python。

## GitHub Pages部署（网页操作，无需命令行）

1. 登录GitHub，创建你自己的仓库，例如 `silvercare-learning`。使用公开仓库可以按GitHub免费方案的Pages规则发布；私有仓库需核对账户方案是否支持。
2. 在仓库中选择 **Add file → Upload files**。把解压文件夹内的文件直接上传到仓库根目录，至少包含：
   - `index.html`：页面结构与站内部署指南。
   - `style.css`：响应式与暗色样式。
   - `data.js`：30天完整课程、数学、实验与验收要求。
   - `app.js`：打卡、进度、搜索、笔记及备份功能。
   - `favicon.svg`：图标。
   - `课程原计划.md`、`README.md`：可下载文档。
3. 提交到 `main` 分支。不要仅上传ZIP；不要把 `index.html` 放在额外的嵌套文件夹中。
4. 打开仓库 **Settings → Pages**。
5. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
6. **Branch** 选择 `main`，目录选择 `/(root)`，点击 **Save**。
7. 在 **Actions** 等待Pages部署任务成功，再返回 **Settings → Pages**，点击GitHub显示的网站链接。
8. 普通项目站点通常为 `https://用户名.github.io/仓库名/`。如果仓库名恰好是 `用户名.github.io`，通常使用用户站点根域名。请以GitHub实际显示的地址为准。

本项目使用独立仓库 silvercare-learning，通过 GitHub Pages 从 main 分支根目录发布。后续修改并推送网站文件到 main，可触发更新。

官方步骤：[配置Pages发布来源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

### 常见问题

- **404**：核对Pages选择的分支/目录、根目录是否存在小写 `index.html`，以及Actions是否成功。
- **无样式或无课程**：确认5个必需静态文件完整、名称大小写一致、相对路径未改动；刷新页面。
- **更新没出现**：先确认最新Pages任务成功，再强制刷新；不要通过清除全部站点数据解决缓存，以免删除学习记录。
- **更换设备没有进度**：记录不会云同步；在原设备导出JSON，再在新设备导入。
- **从本地文件迁移到Pages后没有进度**：不同地址使用独立存储，在原地址导出再导入。
- **保存失败**：网站会显示错误，当前页面仍保留改动；立即导出备份，再检查浏览器存储权限或剩余空间。

## 日常自学版

- 30天、6阶段；每阶段四天知识与编程学习，第五天做串联实践与复盘。页面不显示周次映射。
- 每天详细展开三个概念、一个具体例子、四步动手实验和三个简单自查问题；部分课程另附可复制的起步代码。
- “今日打卡”只有理解了、做过了、检查过了三项，不需要上传成果、评分或提交正式报告。
- 进度按90项自查统计；三项完成即完成一天，阶段实践仍保留在D5、D10、D15、D20、D25、D30。
- 原有完整实验、交付物与项目目标放入“进阶参考”，有余力再做，不作为每日打卡操作。
- 保留搜索、阶段/状态筛选、每日笔记、笔记汇总、备份导入导出、明暗模式和手机适配。
- 导入校验日期、版本、任务索引和笔记长度；导入上限12MB，每日笔记上限50000字符，替换前可以先导出。
- 键盘页签支持方向键、Home与End，日期链接如 `#day-19` 可以直接打开对应课程。

## 旧记录兼容

原有笔记与旧版JSON备份继续可用。旧打卡归入理解、动手、自查三组：同组原任务全部完成时，该项才显示完成；部分勾选仍保留，可能尚未凑满一个新自查项。因此显示百分比可能变化，原记录没有被清空。导入仍会替换当前记录，请先导出备份。

## 课程与环境

原课程的知识主题和六阶段项目继续保留。按自己的节奏学，30天是内容顺序，不是必须赶完的期限。先理解概念与例子，再动手修改输入观察结果，最后做简单自查；笔记写几句即可。需要系统强化时，再打开“进阶参考”补全原项目目标。

Python、NumPy、OpenCV、PyTorch、Open3D实验在自己的开发环境执行；机器人部分采用Ubuntu 24.04＋ROS 2 Jazzy＋Gazebo Harmonic，参考[官方兼容组合](https://gazebosim.org/docs/harmonic/ros_installation/)。Nav2链接指向[Jazzy版本教程](https://docs.nav2.org/jazzy/getting_started/)。网站负责课程与学习记录，不在浏览器内运行Python、ROS或仿真，不提供自动实验评分。

## 记录与隐私

进度、笔记和主题保存在当前站点下的浏览器 `localStorage`（键名 `silvercare-learning-v1`），无账号、无遥测、无上传记录。外部文档链接由用户点击后打开。清理浏览器数据、无痕模式关闭、换域名或换协议可能导致原记录不可见。请定期导出备份；导入会替换本机记录，不能自动合并。

不要在学习笔记中保存真实老人的健康信息、摄像头私密画面或密钥。最终项目是仿真学习原型，不能直接作为真实康养产品使用；课程验收不替代物理安全验证。

## 修改课程

编辑 `data.js` 中每日的 `study` 字段可修改详细讲解、例子、动手步骤、三项自查与起步代码。原 `steps` 等字段仍为“进阶参考”和旧记录兼容保留；不要直接删改旧任务顺序。更新前建议先导出学习备份。无需安装前端依赖或运行构建。

网站源码与课程记录格式都随本交付提供；官方项目与文档遵循各自许可。课程中的模型、数据与实验工具须按各项目说明自行安装和下载。
