# 30天具身智能学习平台

一个给自己日常学习使用的中文网站。从坐标变换与视觉感知开始，逐步学习机器人通信、仿真导航、语言任务规划与系统集成。课程按30天组织，可以停下来复习，也可以把一天的内容分几次完成。

**[在线学习](https://lazielz.github.io/silvercare-learning/)** · **[第1天课程](https://lazielz.github.io/silvercare-learning/lesson.html?day=1)**

## 怎么使用

1. 在首页查看30天课程地图，选择想学的一天。
2. 点击课程卡片，进入单独的课程详情页。
3. 先读概念与具体例子，再在自己的开发环境跟着步骤动手。
4. 完成后，在“今日打卡”勾选“理解了、做过了、检查过了”。每天只有三项，不用交报告或上传文件。
5. 有问题就写几句笔记，下次接着学。有余力时，再看“进阶参考”的完整实验目标。

详情页支持上一天、下一天和返回课程地图；链接可以收藏，刷新后仍是当前课程。

## 学什么

- **D1–5：机器人数学与视觉感知**。NumPy、向量矩阵、三维位姿、相机模型、OpenCV、PyTorch与目标检测。
- **D6–10：三维感知与空间记忆**。目标跟踪、概率统计、RGB-D、Open3D点云、空间关系与SQLite物品记忆。
- **D11–15：ROS 2机器人工程**。节点、Topic、Service、Action、TF2、PID、URDF、RViz、Launch与数据回放。
- **D16–20：仿真与自主导航**。Gazebo家居环境、栅格地图、Dijkstra、A*、Nav2、SLAM Toolbox与RTAB-Map。
- **D21–25：语言规划与主动感知**。语音转写、意图解析、任务状态机、行为树、动作校验、信息增益搜索与系统集成。
- **D26–30：测试、性能与交付**。超时与取消、故障处理、自动化测试、指标评估、性能测量和最终找物演示。

每个阶段四天学习、一天实践。最终练习是让仿真机器人接收找物指令，查询记忆、移动观察，并给出可信的结果。30天表示学习顺序，不是必须赶完的期限。

## 页面功能

- 30天课程地图、整体进度和分阶段进度。
- 独立课程页面，包含详细概念、数学例子、分步实验与简单自查；部分课程附起步代码。
- 三项打卡、每日笔记与笔记汇总。
- 关键词搜索、阶段与学习状态筛选。
- 官方教程与开源项目链接。
- JSON备份导出、导入，浅色与暗色模式。
- 电脑和手机布局，键盘可操作的页签与表单。

## 学习记录与备份

打卡、笔记和主题只保存在当前浏览器中，不需要账号，不会自动上传到GitHub，也不会自动跨设备同步。

换设备或从本地文件版迁移到在线版时：在原页面点击“导出备份”，保存JSON，再在新页面点击“导入备份”。导入会先显示预览，确认后替换现有记录，建议提前导出当前版本。

清除浏览器数据或结束无痕会话可能丢失记录，请定期备份。单日笔记最多50000字符，导入文件最多12MB。旧版笔记与备份继续兼容；三项自查对应旧版任务分组，部分勾选会保留。

## 本地打开

将仓库下载解压后，双击 `index.html` 即可打开。若要获得更稳定的本机存储行为，也可在文件夹中运行：

```sh
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。网站无需安装前端依赖，也没有构建步骤。

Python、图像处理、ROS和仿真实验需要在自己的开发环境运行；网页不会执行这些实验。机器人部分沿用Ubuntu 24.04、ROS 2 Jazzy与Gazebo Harmonic，安装与接口以对应官方文档为准。

## 部署与更新

当前网站通过GitHub Pages发布，来源为本仓库的 `main` 分支根目录。向 `main` 提交更新后，GitHub会重新发布；可在仓库的Actions页面查看结果。

部署自己的副本时：

1. 将上述静态文件上传到自己的GitHub仓库根目录，不要只上传ZIP，也不要漏掉 `lesson.html`。
2. 打开 **Settings → Pages**，Source选择 **Deploy from a branch**。
3. 选择 **main** 与 **/(root)**，保存。
4. 等待发布完成，打开GitHub显示的站点地址。

页面使用相对路径，可以部署在项目子目录。更新JavaScript、CSS或课程数据时，也应更新两个HTML文件中的资源版本参数，以避免浏览器沿用旧缓存。若仍显示旧版，可强制刷新，别通过清除全部浏览器数据解决缓存问题。

## 修改课程

日常学习内容在 `data.js` 各天的 `study` 字段中：`goal`是学习目标，`concepts`是概念讲解，`worked`是例子，`lab`是动手步骤，`checks`是三项自查，`code`是可选示例。

“进阶参考”与旧记录沿用其他课程字段。更改内容前先导出备份，避免随意删除或重排旧任务索引。首页与详情页共用 `app.js`、`style.css` 和 `data.js`；修改公共导航时需同步两个HTML页面。

## 使用范围

这是个人学习与仿真练习平台，打卡属于自查，不是自动评测。示例和课程不代表真实机器人已经达到产品可靠性或安全要求，实物测试需另外验证。模型、数据集和外部开源工具遵循各自许可。
